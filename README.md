# Merging_lineage_kMC

This repository contains Python scripts for a stochastic kinetic Monte Carlo (kMC) simulation of particle merging and state changes.
The code tracks lineage data for each particle and saves the results in an SQLite database for later analysis.

## Main Features
- Stochastic kMC simulation of particle merging based on merging barrier
- Lineage tracking for particle state changes and analysis of database files for growth physics. 
The scripts are used to study:
- multiplicative vs. additive growth
- log-normal vs. normal distributions
- particle merging statistics and lineage behavior tree
